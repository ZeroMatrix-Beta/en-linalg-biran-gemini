\chapter{Set Theory}

In this chapter, we formalize the language of sets, which provides the universal framework for all modern mathematical structures, including the vector spaces we will investigate later.

\subsection{Basic Definitions and Notation}

\begin{definition}[Set]
\label{def:set}
A \newterm{set} is a collection of distinct objects, which are referred to as the \textit{elements} of the set.
\end{definition}

In our notation, we denote sets typically by capital letters. If an object $x$ is an element of a set $M$, we write $x \in M$. If it is not, we write $x \notin M$.

\begin{remark}
Crucially, within a set, the order of elements is irrelevant, and repetitions do not contribute to the set's identity. For example:
\[
M = \{1, 3, \text{moon}\} = \{3, \text{moon}, 1\}
\]
\[
M = \{1, 1, 1\} = \{1\}
\]
\end{remark}

We frequently define sets using a property or condition $A(x)$ that the elements must satisfy. The standard notation for this \qt{set-builder} form is:
\[
M = \{x \mid A(x)\} \quad \text{or} \quad M = \{x : A(x)\}
\]

\begin{example}[Set-Builder Notation]
The set of integers whose square is less than or equal to $9$ is written as:
\[
\{x \in \mathbb{Z} \mid x^2 \le 9\} = \{-3, -2, -1, 0, 1, 2, 3\}
\]
\end{example}

\begin{definition}[The Empty Set]
\label{def:empty_set}
The \newterm{empty set}, denoted by $\emptyset$ or $\{\}$, is the unique set containing no elements.
\end{definition}

It is important to note that a set is allowed to contain another set as one of its elements. For instance, consider the set $M = \{1, \text{elephant}, \{a, 5\}\}$. Here, the set $\{a, 5\}$ is a single element of $M$. Similarly, we can define a set containing only the empty set: $M = \{\emptyset\}$, which is a set containing exactly one element.

\subsection{Subsets and Inclusion}

We now define how sets relate to one another in terms of containment.

\begin{definition}[Subset and Proper Subset]
\label{def:subset}
Let $P$ and $Q$ be sets.
\begin{enumerate}
    \item We say $P$ is a \newterm{subset} of $Q$, denoted $P \subseteq Q$, if every element of $P$ is also an element of $Q$. Formally: $\forall x \in P : x \in Q$.
    \item We say $P$ is a \newterm{proper subset} of $Q$, denoted $P \subsetneq Q$, if $P \subseteq Q$ and $P \ne Q$. 
    \item We write $P \not\subseteq Q$ to denote that $P$ is not a subset of $Q$, meaning $\neg(P \subseteq Q)$.
\end{enumerate}
\end{definition}

\begin{remark}
Note that some authors use $P \subset Q$ to denote proper subsets, while others use it for generic subsets.
\end{remark}

\begin{example}[Subsets and Non-Subsets]
\label{ex:subset_examples}
We have
\[
\{-1, 2, 5\} \subsetneq \{x \mid x \text{ is an integer and } x^2 \le 30\},
\]
the inclusion being proper because, for instance, $0$ lies in the right-hand set but not in the left. On the other hand,
\[
\{-1, 2, 5\} \not\subseteq \{x \mid x \text{ is an integer and } x^2 \le 20\},
\]
since $5^2 = 25 > 20$.
\end{example}

\begin{claim*}
\label{claim:empty_set_is_subset}
For any set $Q$, the empty set is a subset of $Q$ (i.e., $\emptyset \subseteq Q$).
\end{claim*}

% Creator: Opus 5
\begin{proof}
By \cref{def:subset}, $\emptyset \subseteq Q$ means $\forall x \in \emptyset : x \in Q$. There is no $x \in \emptyset$, so the premise of that implication is never satisfied, and the statement is vacuously true in the sense of the Remark following \cref{def:implication}. It is worth pausing on this, because it is the first place where the convention that an implication with a false premise counts as True does real work rather than producing a curiosity about flat Earths.
\end{proof}

\subsection{Set Operations}

Just as we have logical operators for statements, we have operations to combine or modify sets.

\begin{definition*}[Intersection, Union, Difference and Complement]
\label{def:set_operations}
Let $A$ and $B$ be subsets of a universal set $X$.
% Extractor: Gemini 3.1 Pro
\begin{enumerate}
    \item \textbf{Intersection:} $A \cap B := \{x \in X \mid x \in A \wedge x \in B\}$.
    \item \textbf{Union:} $A \cup B := \{x \in X \mid x \in A \vee x \in B\}$.
    \item \textbf{Difference:} $A \setminus B := \{x \in X \mid x \in A \wedge x \notin B\}$.
    \item \textbf{Complement:} The complement of $A$ in $X$ is $A^c := X \setminus A = \{x \in X \mid x \notin A\}$.
\end{enumerate}
\end{definition*}

\begin{definition}[Symmetric Difference]
\label{def:symmetric_difference}
The \newterm{symmetric difference} of $A$ and $B$ is defined by
\[
A \bigtriangleup B := (A \cup B) \setminus (A \cap B).
\]
\end{definition}

\begin{notation}
The set $X$ above is called the \newterm{ambient set}, or the underlying set (in German, \germanterm{Grundmenge}), of the discussion. The complement of $A$ in $X$ is sometimes also written $\overline{A}$ rather than $A^c$.
\end{notation}

\subsection{Unions and Intersections of Families of Sets}

The operations $\cap$ and $\cup$ are not restricted to two sets; they extend to arbitrary collections.

\begin{definition}[Union and Intersection of a Family]
\label{def:family_union_intersection}
Let $\mathcal{A}$ be a family (that is, a set) of sets with $\mathcal{A} \ne \emptyset$. We define
\begin{align*}
\bigcup_{A \in \mathcal{A}} A &:= \{ x \mid \exists A \in \mathcal{A} \text{ such that } x \in A \}, \\
\bigcap_{A \in \mathcal{A}} A &:= \{ x \mid \forall A \in \mathcal{A} : x \in A \}.
\end{align*}
\end{definition}

In practice, $\mathcal{A}$ sometimes merely parametrises, or indexes, a family of sets.

\begin{example}[An Indexed Family]
\label{ex:indexed_family}
Let $\mathcal{A} = \{2, 3, 4, \dots\}$ and, for every $n \in \mathcal{A}$, set
\[
A_n := \{ x \mid x \in \mathbb{Z}, \ x \ge 1, \text{ and } n^2 \text{ divides } x \}.
\]
Thus $A_2 = \{4, 8, 12, \dots\}$, $A_3 = \{9, 18, 27, \dots\}$, and so on. Then
\[
\bigcup_{n \in \mathcal{A}} A_n = \{ a \in \mathbb{Z} \mid \exists k, r \in \mathbb{Z}, \ k, r \ge 1, \text{ such that } a = k^2 \cdot r \},
\qquad
\bigcap_{n \in \mathcal{A}} A_n = \emptyset .
\]
The union is drawn in \cref{fig:indexed_family}. The intersection is empty because no integer $x \ge 1$ is divisible by $n^2$ for \textit{every} $n$: any such $x$ would exceed every bound.
\end{example}

\begin{ainote}
As written in the notes, the condition describing the union allows $k = 1$, and with $k = 1$ the equation $a = k^2 \cdot r$ is satisfied by \textit{every} $a \ge 1$. Taken literally the right-hand side would therefore be all of $\{a \in \mathbb{Z} \mid a \ge 1\}$, which is not the union of the $A_n$. Since the index set is $\mathcal{A} = \{2, 3, \dots\}$, the intended condition is $k \ge 2$, so that
\[
\bigcup_{n \in \mathcal{A}} A_n = \{ a \in \mathbb{Z} \mid a \ge 1 \text{ and } a \text{ is divisible by the square of some } k \ge 2 \},
\]
that is, the positive integers that are \textit{not} squarefree. This is what \cref{fig:indexed_family} shows.
\end{ainote}

\subsection{Cartesian Products}

To handle ordered pairs and higher-dimensional structures, we introduce the Cartesian product.

\begin{definition}[Cartesian Product]
\label{def:cartesian_product}
The \newterm{Cartesian product} of two sets $X$ and $Y$ is the set of all ordered pairs $(x, y)$ where $x \in X$ and $y \in Y$:
\[
X \times Y := \{(x, y) \mid x \in X, y \in Y\}
\]
\end{definition}

\begin{example}[A Finite Cartesian Product]
\label{ex:finite_cartesian_product}
Let $X = \{1, 2, \text{elephant}\}$ and $Y = \{4, \text{dog}\}$. Then
\[
X \times Y = \{(1,4), \, (1,\text{dog}), \, (2,4), \, (2,\text{dog}), \, (\text{elephant},4), \, (\text{elephant},\text{dog})\}.
\]
The pairs are \textit{ordered}, and this matters: $(1,4) \in X \times Y$, whereas $(4,1) \notin X \times Y$.
\end{example}

This construction generalizes to $n$ sets. We denote the $n$-fold product of a set $X$ with itself as $X^n$:
\[
X^n := \underbrace{X \times \dots \times X}_{n \text{ times}} = \{(x_1, \dots, x_n) \mid x_i \in X \text{ for } 1 \le i \le n\}
\]
The elements of $X^n$ are called $n$-tuples. For example, $X^2 := X \times X$, and $X^3 := X \times X \times X = \{(x_1, x_2, x_3) \mid x_1, x_2, x_3 \in X\}$, and so forth.

\begin{example}[Cartesian Products in the Plane]
If $X = \mathbb{R}$, then $X^2 = \mathbb{R} \times \mathbb{R} = \mathbb{R}^2$ represents the standard Euclidean plane. If we take $X = [0, 2]$ and $Y = [1, 2]$, then $X \times Y$ represents a rectangle in the plane with corners at $(0,1), (2,1), (0,2),$ and $(2,2)$, as drawn in \cref{fig:cartesian_rectangle}.
\end{example}

\subsection{Power Sets and Cardinality}

\begin{definition}[Power Set]
\label{def:power_set}
Let $X$ be a set. The \newterm{power set} of $X$, denoted by $\mathcal{P}(X)$ or $2^X$, is the set of all subsets of $X$:
\[
\mathcal{P}(X) := \{Q \mid Q \subseteq X\}
\]
\end{definition}

\begin{example}[Power Set of a Finite Set]
For $X = \{1, 2, 3\}$, the power set is:
\[
\mathcal{P}(X) = \{\emptyset, \{1\}, \{2\}, \{3\}, \{1, 2\}, \{1, 3\}, \{2, 3\}, \{1, 2, 3\}\}
\]
Note that $\mathcal{P}(X)$ contains $8$ elements.
\end{example}

\begin{definition}[Cardinality]
\label{def:cardinality}
If $X$ is a finite set, meaning a set with finitely many elements $X = \{x_1, \dots, x_n\}$, we say that the \newterm{cardinality} of $X$ is the number of elements in $X$, denoted by $|X| := n$ or $\text{card}(X) := n$.
\end{definition}

\begin{exercise}[Cardinality of the Power Set]
\label{exc:power_set_cardinality}
Let $A$ be a finite set. Prove by induction that the cardinality of its power set is given by:
\[
|\mathcal{P}(A)| = 2^{|A|}
\]
\end{exercise}

\subsection{A Note on the Foundations: Russell's Paradox}

In the early development of set theory, it was assumed that any property $A(x)$ could define a set (Naive Set Theory). However, Bertrand Russell showed that this leads to a contradiction.

Suppose there exists a \qt{set of all sets}, denoted by $S$. We then define a subset $R \subseteq S$ as follows:
\[
R := \{P \in S \mid P \notin P\},
\]
that is, $R$ is the set of all sets that do not contain themselves. For example, $S$ itself is a set, so $S \in S$, and therefore $S \notin R$.

Now, we ask: is $R$ an element of itself?
\begin{itemize}
    \item If $R \in R$, then by the definition of $R$, it must be that $R \notin R$. This is a contradiction.
    \item If $R \notin R$, then by the definition of $R$, it must be that $R \in R$. This is also a contradiction.
\end{itemize}
The two implications close into the cycle drawn in \cref{fig:russell_cycle}: each of the only two possible answers forces the other one.

\begin{figure}[ht!]
  \centering
  \begin{tikzpicture}[>=Stealth, node distance=3.6cm]
    \node[draw=ThemePurple, thick, rounded corners=3pt, inner sep=6pt] (in)  {$R \in R$};
    \node[draw=ThemePurple, thick, rounded corners=3pt, inner sep=6pt, right=of in] (out) {$R \notin R$};
    \draw[->, ThemeAccent, thick] (in) to[bend left=28]
      node[above, font=\scriptsize, text=ThemeAccent] {by definition of $R$} (out);
    \draw[->, ThemeAccent, thick] (out) to[bend left=28]
      node[below, font=\scriptsize, text=ThemeAccent] {by definition of $R$} (in);
  \end{tikzpicture}
  \caption{Russell's paradox as a cycle. A statement and its negation imply one another, so neither can be assigned a truth value. The fault lies not in the reasoning but in the assumption that $S$ is a set.}
  \label{fig:russell_cycle}
\end{figure}

\begin{claim*}
\label{claim:russell_no_set}
Neither $S$ nor $R$ can be regarded as a set.
\end{claim*}

% Creator: Opus 5
\begin{proof}
Both halves are the contradiction just derived, read backwards. If $R$ were a set, then \qt{$R \in R$} would be a mathematical statement in the sense of \cref{def:mathematical_statement}, and so would have exactly one of the truth values T and F; the two bullet points above show that each of them forces the other, so it has neither. Hence $R$ is not a set. And if $S$ were a set, then $R$ would be one too, being carved out of $S$ by the property $P \notin P$, which is the only step in the construction of $R$ that needs justifying. So $S$ is not a set either.

Notice which assumption is being discarded. Nothing in the derivation is faulty: what fails is the naive principle that every property defines a set. The axiomatic theories mentioned below replace that principle by one that only allows a property to carve a subset out of a set already known to exist, which is exactly the step that this argument turns against itself.
\end{proof}
% Extractor: Gemini 3.1 Pro

This paradox led to the development of Axiomatic Set Theory (e.g., Zermelo-Fraenkel), which places specific restrictions on how sets can be constructed to ensure mathematical consistency.

\subsection{Solutions to the Exercises}
\label{sec:solutions_set_theory}

\begin{exercisesolution}[Proof of \cref{exc:power_set_cardinality}]
We induct on $n := |A|$, the cardinality of \cref{def:cardinality}.

\textbf{Base, $n = 0$.} The only set with no elements is $\emptyset$, and its only subset is $\emptyset$ itself: it is one, by the Claim on \cpageref{claim:empty_set_is_subset}, and any other would have to contain an element of $\emptyset$, of which there are none. So $\mathcal{P}(\emptyset) = \{\emptyset\}$, which has one element, and $2^0 = 1$.

\textbf{Step.} Suppose the claim holds for every set of cardinality $n$, and let $|A| = n+1$. Since $n + 1 \ge 1$ we may pick an element $a \in A$; put $A' := A \setminus \{a\}$, so that $|A'| = n$. Split the subsets of $A$ according to whether they contain $a$:
\[
    \mathcal{P}(A) = \underbrace{\{Q \subseteq A \mid a \notin Q\}}_{=: \, \mathcal{Q}_0} \; \cup \; \underbrace{\{Q \subseteq A \mid a \in Q\}}_{=: \, \mathcal{Q}_1},
\]
and this union is disjoint, since no $Q$ can both contain $a$ and not contain it.

A subset of $A$ avoiding $a$ is precisely a subset of $A'$, so $\mathcal{Q}_0 = \mathcal{P}(A')$ and $|\mathcal{Q}_0| = 2^n$ by the induction hypothesis. For $\mathcal{Q}_1$, the assignment
\[
    \mathcal{P}(A') \longrightarrow \mathcal{Q}_1, \qquad Q' \longmapsto Q' \cup \{a\},
\]
is a bijection: it lands in $\mathcal{Q}_1$; it is injective, because removing $a$ again recovers $Q'$; and it is surjective, because any $Q \in \mathcal{Q}_1$ is the image of $Q \setminus \{a\} \subseteq A'$. Hence $|\mathcal{Q}_1| = |\mathcal{P}(A')| = 2^n$ as well.

Adding the two disjoint parts,
\[
    |\mathcal{P}(A)| = 2^n + 2^n = 2^{n+1} = 2^{|A|},
\]
which completes the induction.

The example above is the case $n = 3$: the eight subsets of $\{1,2,3\}$ split into the four that avoid $3$, which are the subsets of $\{1,2\}$, and the four obtained from those by adjoining $3$. This is also where the alternative notation $2^X$ for the power set comes from.
\end{exercisesolution}

\begin{ainote}
A linear algebra course opens with set theory not because the theory is needed in
any depth, but because three of its constructions are the raw material of
everything after. The Cartesian product of \cref{def:cartesian_product} is what
makes $K^n$ an object at all, and later the domain of a bilinear form
$B \colon V \times V \to K$. The subset relation of \cref{def:subset} becomes the
linear subspace, the most-used notion in the book, and with it the two-inclusion
proof pattern that recurs on almost every page. The family union and intersection
of \cref{def:family_union_intersection} are what let the span of an arbitrary set
be defined as an intersection of subspaces in ch. 8, where the index family is
genuinely infinite.

Russell's paradox at the end is not a curiosity either. It is why every
construction here carves a new object out of one already known to exist, rather
than collecting everything with a given property. \qt{The set of all vector
spaces} is not available, which is why the isomorphism results of chs. 15 and 18
are always stated between two given spaces.
\end{ainote}
